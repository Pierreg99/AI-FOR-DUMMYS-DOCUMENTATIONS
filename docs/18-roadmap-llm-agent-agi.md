# Kapitel 18 — Roadmap: LLM → Agent → AGI

## Phase 0 — Foundation Model
Model quality, instruction following und Kontextverarbeitung.

## Phase 1 — Tool-Augmented Model
Structured tool calls plus Runtime.

## Phase 2 — Agent
Goal + control loop + state + tools + verification.

## Phase 3 — Reliable Agent
Durable state + retries + evaluation + security + observability.

## Phase 4 — Long-Horizon Agent
Memory + Planung + Recovery + persistent execution.

## Phase 5 — Multi-Agent Fabric
Specialists + orchestration + shared state + protocols.

## Phase 6 — Generality Research
Robuster Transfer über viele Aufgaben und Domänen.

## Phase 7 — AGI Evaluation Space
```text
Performance × Generality × Autonomy
```

## Kernunterscheidung
```text
LLM  = model
Agent = acting system
AGI  = general capability concept
ASI  = hypothetical super-capability
```
