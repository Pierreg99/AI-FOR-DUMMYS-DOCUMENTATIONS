# Kapitel 5 — Generative AI

Generative AI erzeugt neue synthetische Inhalte, etwa Text, Bilder, Audio, Video oder Code.

```text
Generative AI
├── Text
├── Image
├── Audio
├── Video
└── Code
```

LLMs sind eine wichtige Unterklasse generativer Systeme, aber nicht die gesamte GenAI-Landschaft.
