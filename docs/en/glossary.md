# Glossary

Terms for quick reference. The chapters explain their applications and limits.

| Term | Explanation |
| --- | --- |
| Agent | A system that selects next steps using a goal and observations. |
| AGI | A concept of broad general AI capability with differing definitions. |
| ASI | A hypothetical concept of broadly superhuman intelligence. |
| Attention | A mechanism connecting information across representations. |
| Backpressure | Limiting new work when processing cannot keep up. |
| Checkpoint | Persisted execution state that supports resumption. |
| Chunk | A content segment prepared for retrieval or processing. |
| Context window | The bounded information space available to a model call. |
| Embedding | A vector representation of content, not proof of truth. |
| Evaluation | Systematic assessment against defined tasks and criteria. |
| Fine-tuning | Additional training that adjusts model parameters. |
| Foundation model | A broadly pretrained model used as a starting point for different tasks. |
| Halluzination / Hallucination | Plausible-looking output that is unsupported or false. |
| Idempotenz / Idempotency | Repeating the same operation creates no additional effect. |
| Inference | Applying learned model parameters to an input. |
| Lease | Time-limited ownership of a unit of work. |
| LLM | Large language model. |
| MCP | Model Context Protocol: a protocol for context and tool integrations. |
| Memory | Stored information retrievable for later steps. |
| Precision | The relevant fraction of returned results. |
| Prompt Injection | An attempt by untrusted content to redirect system behavior. |
| Provenienz / Provenance | Traceable origin and version of information. |
| RAG | Retrieval-augmented generation: generation using retrieved evidence. |
| Recall | The retrieved share of all known relevant entries. |
| Reranking | Reordering previously retrieved search candidates. |
| Sandbox | A restricted execution environment with enforced access boundaries. |
| Token | A text unit determined by a tokenizer. |
| Tool calling | A structured proposal to invoke an external function. |
| Trace | A connected record of an execution’s steps. |
| Workflow | A largely predefined control path for a task. |
