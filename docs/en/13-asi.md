# ASI and future concepts

Separate hypothetical superintelligence from observed capabilities and technical development plans.

## Learning goal

State a future assumption explicitly as an assumption. Artificial superintelligence describes hypothetical systems whose broad cognitive capabilities would substantially exceed human capabilities. The term does not identify a specific software architecture.

## Separating kinds of claims

| Claim type | Example | Required basis |
| --- | --- | --- |
| Observation | A system solves a particular test | Test data and conditions |
| Engineering goal | An agent should recover from failures | Implementation and verifiable criteria |
| Research hypothesis | A method might generalize more broadly | Methodology and new experiments |
| Future scenario | Highly capable systems change institutions | Explicit assumptions and alternatives |

A progression from narrow AI through AGI to ASI is one conceptual presentation. It is not an established technical sequence or timetable.

## Worked example

A team designing a knowledge platform can implement permissions, model substitution, shutdown, and data export today. It need not predict an ASI arrival date or treat one future as certain. Comparing scenarios can help identify decisions that remain useful across different outcomes.

## Limits and open questions

Claims about recursive self-improvement, control, or social consequences contain substantial assumptions. Ask which resources, feedback mechanisms, and external dependencies they require. A better test score does not prove an unlimited capacity for improvement.

Discuss uncertainty symmetrically: neither a possible risk nor a possible benefit is already an observed condition. Avoid precise-looking arrival dates without a defensible method. Keep measurable engineering commitments separate from expectations about long-term capabilities.

## Exercise

Reframe “AI will inevitably take over all research” as a bounded, testable question.

## Answer and self-check

For example: “How does this system change completion time and quality for a defined literature review under documented human supervision?” This states a task, metrics, and conditions. It does not replace a long-term forecast, but it produces checkable evidence.
