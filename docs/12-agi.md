# Kapitel 12 — Artificial General Intelligence

## AGI als Fähigkeitskonzept
AGI bezeichnet ein hypothetisches bzw. definitorisch unterschiedliches Niveau allgemeiner KI mit hoher Leistung über eine breite Menge von Aufgaben.

## Drei nützliche Dimensionen
```text
Performance × Generality × Autonomy
```

## AGI ≠ Agent
Ein autonomer Agent kann auf eine enge Domäne spezialisiert sein.

## AGI ≠ großes LLM
Ein großes Modell kann breite Fähigkeiten zeigen, ohne dass dadurch eine universell akzeptierte AGI-Grenze erreicht wäre.

## Evaluation
Es gibt keinen universell verbindlichen AGI-Abschlusstest. Definitionen und Benchmarks unterscheiden sich.
