# Glossar

| Begriff | Bedeutung |
|---|---|
| AI / KI | Artificial Intelligence / Künstliche Intelligenz |
| ANI | Artificial Narrow Intelligence |
| AGI | Artificial General Intelligence |
| ASI | Artificial Superintelligence |
| Agent | Zielorientiertes, interaktiv handelndes System |
| Agentic AI | Paradigma für adaptive, zielorientierte KI-Systeme |
| Context Window | Für einen Modellaufruf verfügbarer Kontext |
| Foundation Model | Breit vortrainiertes und für mehrere Aufgaben nutzbares Modell |
| GenAI | Generative Artificial Intelligence |
| LLM | Large Language Model |
| ML | Machine Learning |
| RAG | Retrieval-Augmented Generation |
| Tool Calling | Strukturierter Aufruf externer Funktionen durch ein Modell |
| Workflow | Überwiegend vorab definierter Ausführungspfad |
| Memory | Temporäre oder persistente Agentinformationen |
| Embedding | Vektorielle Repräsentation von Inhalt |
| Orchestrator | Koordinator von Agenten und Ausführungsschritten |
| Human-in-the-loop | Menschliche Kontrolle innerhalb eines Ablaufs |
| Long-horizon task | Aufgabe mit vielen abhängigen Handlungsschritten |
