# Glossar

Begriffe zum Nachschlagen. Die Kapitel zeigen ihre Anwendung und Grenzen.

| Begriff | Erklärung |
| --- | --- |
| Agent | Ein System, das nächste Schritte anhand von Ziel und Beobachtungen auswählt. |
| AGI | Konzept breiter allgemeiner KI-Fähigkeiten mit unterschiedlichen Definitionen. |
| ASI | Hypothetisches Konzept einer weit übermenschlichen allgemeinen Intelligenz. |
| Attention | Mechanismus zum Verknüpfen von Informationen zwischen Repräsentationen. |
| Backpressure | Begrenzung neuer Arbeit, wenn die Verarbeitung nicht nachkommt. |
| Checkpoint | Dauerhaft gespeicherter, wiederaufnehmbarer Ausführungsstand. |
| Chunk | Ein für Suche oder Verarbeitung abgeteilter Inhaltsabschnitt. |
| Context window | Begrenzter Informationsraum eines Modellaufrufs. |
| Embedding | Vektorielle Repräsentation von Inhalt; kein Wahrheitsnachweis. |
| Evaluation | Systematische Bewertung anhand definierter Aufgaben und Kriterien. |
| Fine-tuning | Zusätzliches Training, das Modellparameter anpasst. |
| Foundation model | Breit vortrainiertes Modell als Ausgangspunkt verschiedener Aufgaben. |
| Halluzination / Hallucination | Plausibel wirkende, aber unbelegte oder falsche Ausgabe. |
| Idempotenz / Idempotency | Wiederholung desselben Vorgangs erzeugt keine zusätzliche Wirkung. |
| Inference | Anwendung gelernter Modellparameter auf eine Eingabe. |
| Lease | Zeitlich begrenzte Zuständigkeit für eine Arbeitseinheit. |
| LLM | Large Language Model: ein großes Sprachmodell. |
| MCP | Model Context Protocol: Protokoll für Kontext- und Tool-Integrationen. |
| Memory | Gespeicherte Informationen, die für spätere Schritte abgerufen werden können. |
| Precision | Anteil relevanter Treffer unter den zurückgegebenen Treffern. |
| Prompt Injection | Versuch fremder Inhalte, Systemverhalten unzulässig umzulenken. |
| Provenienz / Provenance | Nachvollziehbare Herkunft und Version einer Information. |
| RAG | Retrieval-Augmented Generation: Generierung mit abgerufenen Belegen. |
| Recall | Anteil gefundener relevanter Einträge an allen bekannten relevanten Einträgen. |
| Reranking | Erneutes Ordnen zuvor gefundener Suchkandidaten. |
| Sandbox | Begrenzte Ausführungsumgebung mit durchgesetzten Zugriffsschranken. |
| Token | Ein durch einen Tokenizer bestimmtes Textelement. |
| Tool calling | Strukturierter Vorschlag zum Aufruf einer externen Funktion. |
| Trace | Verknüpfte Aufzeichnung der Arbeitsschritte einer Ausführung. |
| Workflow | Weitgehend vorab definierter Kontrollpfad einer Aufgabe. |
